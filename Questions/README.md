# Game Programming Problems

Implement these problems in Rust first, then reuse the specifications in the
next language. Every problem is written in three LeetCode-style parts:

1. **Problem** - required game rules and algorithms.
2. **Input and Output** - command format and expected results.
3. **Constraints, Examples, and Requirements** - boundaries, edge cases,
   testing, determinism, and complexity expectations.
